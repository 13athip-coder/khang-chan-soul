# viral-clips — คลิปไวรัลอสังหาฯ (บ้านใหม่วันรับมอบ)

ตัดคลิปแนวตั้ง 15–20 วิ สำหรับ TikTok / Reels / Shorts จากฟุตเทจทัวร์บ้าน
สร้างซ้ำได้ทั้งหมดด้วย `ffmpeg` + `python3` ไม่ต้องใช้โปรแกรมตัดต่อ

## ฟุตเทจต้นฉบับ

10 คลิป · 540×960 · 30fps · รวม 50 วินาที · **ไม่มีเสียงพูด** (วัดได้ -37 ถึง -42 dB = เสียงห้องเปล่า)
เนื้อหา: บ้านใหม่วันรับมอบ ยังตกแต่งไม่เสร็จ — กล่องลัง ที่นอนหุ้มพลาสติก บันไดช่าง

| # | ห้อง | ทิศแพน | ช่วงที่ใช้ได้ |
|---|------|--------|--------------|
| 1 | นั่งเล่น → ตู้ทีวี | A | 0.00–2.60 |
| 2 | นอน A → ตู้กระจก/หัวเตียง | B | 0.60–3.60 |
| 3 | **นอน A → หัวเตียงไฟ LED** | A | 0.10–5.60 |
| 4 | นอน A หน้าต่าง | B | 0.35–3.75 |
| 5 | **ครัว → หน้าต่างต้นไม้เขียว** | A | 4.75–8.50 |
| 6 | นอน B → หน้าต่างสว่าง | A | 0.10–3.90 |
| 7 | นอน B ม่าน/ตู้ | B | 0.10–5.70 |
| 8 | ครัว เครื่องดูดควัน | A | 0.00–2.95 |
| 9 | นั่งเล่น โซฟาคลุมพลาสติก | A | 0.00–3.45 |
| 10 | นั่งเล่น ประตู/ม้านั่ง | B | 0.55–3.35 |

ทิศ A = 6 คลิป, ทิศ B = 4 คลิป — **ไม่กลับภาพซ้ายขวา (mirror)** เพราะผังห้องจะกลับด้าน
คนที่มาดูบ้านจริงจะสับสน ใช้วิธีจัดลำดับให้คลิปทิศเดียวกันอยู่ติดกันแทน

## โครงสร้างการตัด

กริด 100 BPM (1 บีต = 0.6 วิ) ตัดทุก 2 บีต เพื่อให้แปะเพลงเทรนด์ในแอปแล้วลงจังหวะพอดี

```
0.0 – 1.5   hook      นั่งเล่น โซฟา+กล่อง (กล้องแพนอยู่แล้วตั้งแต่เฟรมแรก)
1.5 – 9.9   ไล่ห้อง    1.2 วิ/ห้อง × 7 ห้อง  (นั่งเล่น → ครัว → นอน B → นอน A)
9.9 – 14.7  จุดพลิก    หัวเตียงไฟ LED — เร่ง 1.7x เข้า แล้วชะลอ 0.60x ตอนเผยไฟ
14.7 – 15.3 ลูป        กลับมาโซฟา จบที่เฟรมเดียวกับเฟรมแรกเป๊ะ
```

## เทคนิค

**Whip cut ปลอม** — กล้องในฟุตเทจแพนช้ามาก (3–10 px/เฟรม) ไม่มี whip จริง
จึงสร้างขึ้นที่รอยต่อ: เอา 0.4 วิท้ายช็อต A + 0.4 วิหัวช็อต B มาเร่ง 4x
แล้วใส่ `tmix=frames=5` (เฉลี่ย 5 เฟรมติดกัน) ได้ motion blur เป็นเส้น ตาอ่านว่ากล้องเหวี่ยงจริง

**ลูป** — ช็อตเปิดเริ่มที่วินาที 0.70 ของคลิป 9, ช็อตปิดเล่น 0.10–0.70 ของคลิปเดียวกัน
เฟรมสุดท้าย = เฟรมแรก คนดูวนซ้ำโดยไม่รู้ตัว

**อัปสเกล** 540×960 → 1080×1920 ด้วย lanczos + `unsharp` เบา ๆ

## วิธีรัน

```bash
python3 scripts/make_cut.py /path/to/outdir      # ได้ outdir/base_cut.mp4
```

แก้จังหวะ/ลำดับห้อง: แก้ลิสต์ `SEGMENTS` ใน `scripts/make_cut.py`
`scripts/panscan.py <video> <label>` = วัดทิศและความเร็วแพนของคลิปใหม่

## เสียง

ส่งออกเป็นคลิปเงียบโดยตั้งใจ — ไปใส่เสียงเทรนด์ในแอป TikTok/Reels เอง
(แพลตฟอร์มดันคลิปที่ใช้เสียงในระบบ และไม่มีปัญหาลิขสิทธิ์)
ถ้าจะพากย์ ให้อัดทับทีหลังได้เลย คลิปตัดตามจังหวะ 100 BPM ไว้แล้ว

## สิ่งที่ห้ามทำ

- ห้ามใส่ "สนใจทักแชท" ในตัวคลิป — ฆ่า reach ให้ไปไว้คอมเมนต์ปักหมุด
- ห้ามเปิดด้วยภาพนิ่ง ทุกช็อตแรกต้องกล้องกำลังเคลื่อนอยู่แล้ว
- ห้ามแต่งตัวเลขราคา/ค่าผ่อนที่ไม่มีจริง
