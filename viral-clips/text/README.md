# ตัวหนังสือบนคลิป

ไฟล์ `.ass` (libass) — แก้ข้อความได้ตรง ๆ แล้วรัน `scripts/render_text.sh` ใหม่ ไม่ต้องตัดคลิปใหม่

ฟอนต์: **Kanit** (Google Fonts, OFL) ติดตั้งก่อนเรนเดอร์:
```bash
mkdir -p ~/.fonts
curl -sL -o ~/.fonts/Kanit-Bold.ttf \
  https://raw.githubusercontent.com/google/fonts/main/ofl/kanit/Kanit-Bold.ttf
fc-cache -f
```

## จังหวะตัวหนังสือ (เหมือนกันทุกเวอร์ชัน)

| ช่วง | สไตล์ | หน้าที่ |
|------|-------|---------|
| 0.15–2.20 | Big 112px ขาว | hook — ต้องอ่านจบใน 1 วินาที |
| 10.10–13.40 | Big 112px ขาว | เฉลย/จุดพลิก ตอนหัวเตียง LED โผล่ |
| 13.55–15.80 | Ask 78px เหลือง | ตัวเรียกคอมเมนต์ |

ตำแหน่ง y=740–760 และ 1190 บนพื้นที่ 1080×1920 — หลบ UI ของ TikTok
(แถบล่าง ~25% และปุ่มฝั่งขวา) ห้ามวางต่ำกว่า y=1400

## 3 เวอร์ชัน

- **A** `บ้านยังรกอยู่เลย…` → `…แต่ตรงนี้เสร็จแล้ว` → `ถ้าเป็นคุณ จะแต่งห้องนี้สไตล์ไหน?`
  ประโยคเดียวถูกหั่นครึ่ง เปิดลูปค้างไว้ 10 วินาที คนต้องดูต่อเพื่อรู้ว่า "ตรงนี้" คือตรงไหน
- **B** `นี่คือบ้านก่อนแต่ง` → `อีก 2 เดือน กลับมาดูอีกที` → `เก็บคลิปนี้ไว้ก่อน`
  ขอยอด save ตรง ๆ แลกกับพันธะว่าต้องโพสต์ after จริง
- **C** `ทายซิ ห้องนี้จะแต่งสไตล์ไหน` → `เจ้าของยังไม่ตัดสินใจเลย` → `คอมเมนต์บอกหน่อย`
  เล่นเกมเดาแบบไม่ต้องมีราคา และได้ไอเดียแต่งห้องฟรีจากคอมเมนต์
